## Présentation

**Python Foundations FR** est une collection de documents pédagogiques consacrés aux bases du langage Python.

Cette initiative est née d'une démarche personnelle d'apprentissage, de pratique et de partage des connaissances.

L'objectif est de proposer des ressources accessibles, structurées et progressives, accompagnées d'explications, d'exemples de code et de mises en pratique.

Ces publications ne constituent pas une formation officielle ou certifiante. Chaque document peut être consulté indépendamment, selon les besoins du lecteur.

## Documents disponibles

Les documents sont publiés progressivement au format PDF.

| Document | Contenu | Accès |
|---|---|---|
| Module 00 | Préparer son environnement et exécuter son premier programme Python | Disponible dans le dépôt |
| Module 01 | Variables et types de données | À venir |
| Autres documents | Publication progressive | À venir |

Pour consulter les ressources, ouvrez le dossier du dépôt et sélectionnez le PDF souhaité.

## À qui s'adresse cette collection ?

Ces documents sont destinés notamment :

- Aux personnes qui découvrent la programmation avec Python.
- Aux étudiants souhaitant consolider leurs connaissances.
- Aux autodidactes qui préfèrent apprendre à travers des explications et des exemples pratiques.
- À toute personne souhaitant disposer de ressources Python en français, consultables hors ligne après téléchargement.

## Philosophie de publication

Cette collection repose sur quatre principes :

**Comprendre avant de copier.** Les exemples de code sont accompagnés d'explications pour encourager une véritable compréhension des notions abordées.

**Pratiquer progressivement.** Les documents privilégient des applications concrètes et des exercices ciblés.

**Partager les connaissances.** Les ressources sont publiées gratuitement pour faciliter leur accessibilité.

**Améliorer continuellement.** Les documents peuvent être corrigés, enrichis et actualisés au fil de leur évolution.

## Organisation du dépôt

Ce dépôt est consacré à la diffusion des versions finales des documents PDF.

Les fichiers sources Markdown, les éléments de préparation et les autres ressources de travail ne sont pas publiés ici.
